# MemeX Market v0.69.1

- Исправлена загрузка NFT-превью: Lottie JSON и видео больше не передаются в обычный `<img>`.
- Добавлен последовательный fallback между proxy, сохранённым превью и статическими источниками без сломанной иконки изображения.
- Media proxy теперь изолирует таймаут каждого CDN и продолжает загрузку через следующий источник.
- Canonical media resolver отфильтровывает анимационные и видео URL из полей статических изображений.
- Ошибка загрузки больше не переносится на следующий NFT при повторном использовании компонента.
- Добавлена диагностика полного исчерпания источников без раскрытия URL или пользовательских данных.
