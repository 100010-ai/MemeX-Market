# MemeX Market v0.64.7 — Economy & Performance Polish

Release scope: quality pass across the 16 existing systems requested after v0.64.6. No new large public subsystem was added.

## Changes

1. **Economy / virtual balances**
   - Added shared decimal-comma/non-finite-safe amount parsing.
   - Added upper bounds for trade/admin inputs and non-negative optimistic balance helpers.
   - Kept all currencies virtual and non-withdrawable.

2. **Memecoins**
   - Buy/quote/order/create inputs now use the same amount normalization and bounds.
   - Quote calculations can use the authoritative configured fee instead of assuming a fixed client constant.
   - Preserved the v0.64.4 clean launch state; pristine coins remain 0 public trades/volume until actual market activity.
   - Added minimum-buy and reserve guards around optimistic trading.

3. **Gift Market**
   - Adaptive pagination prefetch for constrained/save-data networks.
   - Concurrent purchase conflicts return HTTP 409 and trigger an authoritative Gift refresh in the UI.
   - Smaller Gift-detail history/offer/event payloads.

4. **Gift detail**
   - Compact “compare / similar lots” handoff back to the same collection market.
   - Listing/offer/alert amounts accept mobile decimal comma safely.
   - Invalid listing prices can no longer be confused with the explicit unlist action.

5. **Portfolio**
   - Initial Gift page reduced to 96 items with bounded continuation pages.
   - Added local Gift and memecoin search while retaining persisted tabs and sorting.

6. **Cases**
   - Rarity-aware reveal timing and restrained visual identity per existing case series.
   - Server-authoritative reward, idempotency, pity and open-again behavior retained.

7. **Battle Pass**
   - Claims, claim-all and prestige now refresh the shared profile/balance state immediately.
   - Remaining XP is surfaced compactly.

8. **Profile**
   - Cleaner identity hierarchy; Telegram numeric ID is no longer used as fallback public copy.
   - Main profile avatar uses the large frame renderer.

9. **Profile frames**
   - Small/constrained-device rendering removes excess orbit/ornament detail and animation/filter cost.
   - Existing frame ownership/equip semantics are unchanged.

10. **Tasks / Achievements / Daily Streak**
    - Focus/visibility refreshes are throttled to avoid duplicate requests.
    - Success notices auto-dismiss and use accessible live regions.

11. **Leaderboard**
    - Tied top-three ranks are handled without duplicating those rows in the normal table.
    - Regular list avatars use the compact frame size.

12. **Notifications**
    - Exact duplicates are collapsed server-side only inside a short five-minute window.
    - Client no longer performs a second independent dedupe pass.

13. **Store**
    - Shorter copy/highlights and explicit unavailable CTA reason instead of a dead-looking button.

14. **Creator Tools**
    - Newly launched/pristine coins show “Новый рынок” instead of empty analytics noise.
    - Retention/buy-sell analytics stay hidden until real public market activity exists.

15. **/control**
    - Balance inputs accept decimal comma and are capped on both client and API.
    - Existing confirmations, before/after audit and duplicate-submit guards remain.

16. **Telegram/mobile + API/performance**
    - Root constrained-device class reduces expensive frame/effect rendering on weaker Android devices.
    - Gift market pagination and portfolio/detail payloads were trimmed to reduce background work.
    - Mobile content uses contained overscroll and compact small-height rules.

## Database

No new migration is required for v0.64.7. `100002_memecoin_market_polish_v0644.sql` remains required if the clean memecoin launch-state update has not yet been deployed.
