# MXM v0.50.0

## AdsGram moderation

- Rewarded-реклама остаётся только добровольной механикой.
- Основной продукт не требует просмотра или клика по рекламе.
- Reward снижен до 1 игрового TON, daily cap — 3, cooldown — 30 минут.
- Добавлена постоянная маркировка: игровой TON не является Toncoin, не выводится и не имеет денежной стоимости.
- Партнёрские задания на подписки/переходы отключены по умолчанию; активные кампании ставятся на паузу миграцией 025.
- Добавлен `/about` с правилами продукта.
- Добавлены публичные `/moderation` и `/reward-confirmations` для проверки рекламной механики и реальных серверных начислений без раскрытия Telegram ID.
- Удалены оставшиеся публичные API старых игровых механик; страница `/games` остаётся безопасным редиректом на маркет.
- Reward callback поддерживает официальный AdsGram `[userId]` placeholder и безопасный no-op probe.
- Добавлен `npm run adsgram:check` для проверки Block ID, HTTPS Web App URL, server secret, bot username и Reward URL.
- Добавлен `ADSGRAM_MODERATION.md` с чеклистом отправки площадки.
