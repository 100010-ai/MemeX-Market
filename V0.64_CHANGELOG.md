# MemeX Market v0.64 — Progression & Compact UI

## Added
- Account progression 1–100 with milestone rewards and post-cap prestige tracking.
- Daily streak rewards with server-authoritative claiming.
- Achievement progress and reward refresh.
- Collection Book progress and milestone claims.
- Case pity counters for Rare / Epic / Legendary rewards.
- Battle Pass prestige rewards after the main reward track.
- New progression page and APIs.
- Case opening roulette animation that visualizes an already server-selected reward.

## UI / UX
- Top header is fixed to the viewport with safe-area handling and content offset.
- Compact page spacing and denser cards/sections.
- Primary buttons use a controlled MXM action style to avoid white WebView button flashes.
- Cases page redesigned with compact case tabs, pity progress, odds and recent-open history.
- Profile frames reworked toward continuous contours, rings and ornamental nodes rather than plain straight-line borders.
- Added Vanguard 100 and Prestige Orbit frame styles.
