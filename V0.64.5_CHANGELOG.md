# MemeX Market v0.64.5 — Release Polish

This release is a quality pass over existing product surfaces. It does not introduce a new economy or database schema. The goal is faster navigation, denser mobile layouts, clearer trading states and stronger pre-deploy verification.

## Product polish

- Replaced the root landing redirect with the actionable `/hub` overview and turned the former feed tab into **Главная**.
- Added compact dashboard sections for market motion, ready tasks, portfolio value, activity and leaderboard position without turning the page into a text wall.
- Reworked Gift detail hierarchy: primary price/floor/offer/24h metrics stay visible, secondary statistics live in a compact disclosure, and player purchases use an explicit two-step confirmation state.
- Improved Gift-market deep links, session restoration and remote search. Search requests are debounced and aborted when superseded.
- Preserved portfolio tab/sort state and added compact handoff actions to Market and Orders.
- Added rarity-aware case reveal feedback while preserving server-authoritative rewards, pity, history, skip and open-again behavior.
- Strengthened Battle Pass current/milestone hierarchy without adding extra explanatory copy.
- Standardized equipped profile-frame rendering in the shared shell and reduced frame ornament noise at small avatar sizes.
- Added high-price-impact confirmation to memecoin Buy/Sell while keeping v0.64.4 launch-state, tiny-price and one-screen terminal fixes.
- Moved task Claim All to one authenticated server-batched request; progression refreshes when the Telegram WebView becomes active again.
- De-duplicates only near-identical notification rows within a five-minute window, preserving legitimate repeated events later.
- Added Telegram keyboard-aware shell behavior and constrained-device preloading for data-saver/2G/low-memory/low-core devices.
- Added off-screen rendering containment to long repeated rows and a compact memecoin market payload for the Home dashboard.
- Added before/after audit snapshots to high-impact `/control` mutations and clearer per-tab counts/search context.

## Release hardening

- New `pnpm run verify` command runs source cleanup, TS/TSX parse validation, local-import validation, release/security checks and the real Next production build.
- `pnpm run verify:static` exists for offline/source-only environments and deliberately skips dependency-backed TypeScript/ESLint/build stages.
- Updated `README.md` and `docs/RELEASE_CHECKLIST.md` to make `pnpm run verify` the canonical production gate.

## Database

No new v0.64.5 migration is required. The v0.64.4 migration `supabase/migrations/100002_memecoin_market_polish_v0644.sql` must already be applied when upgrading from an older database.
