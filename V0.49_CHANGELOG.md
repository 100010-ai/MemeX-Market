# MXM v0.49.0

## Marketplace

- Added collection Sweep for 2 / 5 / 10 cheapest active listings.
- Sweep uses the existing atomic cart-purchase RPC and an idempotency key.
- Added atomic bulk listing for up to 50 owned Gifts.
- Bulk pricing supports one fixed price or collection floor offset (for example `floor -3%`).
- Added collection activity history for listing, repricing, unlisting, expiry and sale events.
- Portfolio analytics now exposes realized and unrealized PnL separately.

## Fixes

- Fixed TonAPI Gifts being hidden from portfolio, orders and public showcases when Bot API `model_file_id` / `symbol_file_id` is unavailable.
- Gift media renderer now supports URL-only media assets.
- Expired listings are excluded from collection browsing, search, cart and active listing surfaces.
- Cart refuses listings whose TTL already expired even before maintenance cleanup runs.
- Collection history no longer fails the whole page when a referenced profile has no display metadata.
- Notification and price-alert mutation endpoints validate IDs before database writes.
