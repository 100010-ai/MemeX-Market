# MXM v0.56.0 — Quality Update + Marketplace 2.0

This release is focused on production hardening, trading correctness and the next marketplace layer rather than adding another isolated section.

## Quality and Telegram WebView

- Added dynamic Telegram viewport handling through `--mxm-viewport-height` and `--mxm-viewport-stable-height`.
- Added Telegram Back Button integration and safe-area-aware application shell behavior.
- Added runtime Maintenance Mode with an admin-editable user-facing message.
- Runtime feature flags now protect server-side mutation routes as well as UI entry points.
- Watchlist duplicate handling and price-alert validation were tightened.

## Marketplace 2.0

- Added collection-wide offers.
- Added model, backdrop and symbol offers.
- Advanced offers reserve the maximum internal TON commitment and support expiration, cancellation and multiple fills.
- Matching owners can accept an advanced offer from a Gift detail flow.
- Added balance reservation awareness to checkout/trading paths.

## Search and discovery

- Added global `Ctrl/Cmd + K` command palette.
- Unified search covers Gifts, collections, users, memecoins and application navigation.
- Search and market endpoints respect runtime feature availability.

## Memecoin conditional orders

- Added limit buy and limit sell.
- Added Take Profit and Stop Loss.
- Buy orders reserve internal TON; sell orders reserve token quantity logically across open sell orders.
- Added order expiration, cancellation and maximum-open-order limits.
- Added idempotent server-side order executor.
- Manual trades and conditional execution now follow consistent locking/idempotency rules to reduce race conditions and deadlocks.

## Admin: Economy, Risk and Health

- Added `/admin/economy-risk` with economy telemetry and risk signals.
- Added minted/burned/circulating TON, fee/reward/referral metrics, inflation indicators and richest-1% visibility.
- Added suspicious paired Gift trading detection, repeated AdsGram-claim detection and Error Inbox aggregation.
- Added `/admin/health` with sanitized status for Supabase, Telegram Bot/webhook, TonAPI, AdsGram, cron/workers and Gift synchronization.
- Added Runtime Config editor for maintenance state, feature flags and operational limits without redeploy.
