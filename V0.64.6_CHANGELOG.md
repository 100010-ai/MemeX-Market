# MemeX Market v0.64.6 — Telegram Compatibility Hotfix

- Telegram WebApp API calls introduced in Bot API 6.1 are now guarded by protocol version checks.
- Header/background color, BackButton, haptics and Stars Invoice no longer call unsupported methods on WebApp 6.0.
- Safe-area/activation events are registered only on supported modern WebApp versions.
- `/api/control/action` no longer turns every database/runtime failure into HTTP 400.
- Control validates common action payloads before sending mutations.
- Gift listing price parsing no longer allows `NaN` to serialize into `null` and accidentally unlist an item.
- Control errors now include the failing action/code locally and use 409/500/503 where appropriate.

No SQL migration is required for v0.64.6.
