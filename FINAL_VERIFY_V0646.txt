Telegram compatibility
----------------------
Bot API/WebApp 6.1 introduced version, isVersionAtLeast, setHeaderColor,
setBackgroundColor, BackButton, HapticFeedback, openTelegramLink and openInvoice.
The SDK can expose these methods while reporting protocol 6.0; optional chaining is
therefore insufficient. v0.64.6 gates 6.1+ calls with telegramVersionAtLeast.
Modern safe-area/activation event setup is separately gated.

Control API
-----------
- Validation failures remain HTTP 400.
- Business/database conflicts use HTTP 409.
- DB schema mismatch uses HTTP 503.
- Unexpected runtime/database failures use HTTP 500.
- Common invalid payloads are rejected client-side before POST.
- Gift listing price refuses NaN/non-positive values and accepts decimal comma.
