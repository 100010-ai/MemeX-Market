# MXM v0.47 — рекламные кампании и маркетинг в админке

## Что появилось

В `/admin` добавлен раздел **«Реклама»**. Он предназначен для партнёрских размещений внутри MXM: администратор может создать задание, назначить награду в виртуальных TON, задать лимит выполнений, расписание, приоритет и способ проверки.

Поддерживаются три режима:

1. **Подписка на Telegram-канал / группу** — автоматическая проверка через Telegram Bot API `getChatMember`.
2. **Переход по ссылке** — MXM фиксирует открытие ссылки и после возврата разрешает получить награду.
3. **Ручная проверка** — игрок отправляет выполнение на проверку, администратор подтверждает или отклоняет его в `/admin`.

Также добавлены **промокоды** с наградой, лимитом активаций и включением/отключением из админки.

## Настройка задания на подписку

1. Добавьте `@MemeXMarketBot` администратором рекламируемого канала или группы.
2. В `/admin` откройте **Реклама** → **Подписка**.
3. Укажите рекламодателя, название, ссылку вида `https://t.me/channel`, награду и число участников.
4. Можно оставить поле `@channel / -100...` пустым, если username есть в ссылке.
5. Выберите `Запустить сразу`.

При активации сервер проверяет, что MXM-бот действительно является администратором указанного чата. Это сделано потому, что Telegram гарантирует проверку `getChatMember` для других пользователей только когда бот является администратором чата.

## Бюджет

В админке показывается максимальный потенциальный бюджет:

`награда × лимит участников`

TON начисляются только после фактического подтверждения выполнения. Для партнёрских наград применяется существующая реферальная механика MXM: реферер получает установленный процент от системной награды приглашённого пользователя.

## Ручные задания

Режим **Ручная** подходит для нестандартных интеграций: оставить заявку, зарегистрироваться на сайте, выполнить действие в стороннем сервисе и т.п. Игрок нажимает «Выполнить», затем отправляет задание на проверку. В админке появляется очередь **«Ручная проверка»** с кнопками `Начислить` и `Отклонить`.

## Защита от ошибок

- одна кампания может быть получена одним аккаунтом только один раз;
- начисление выполняется атомарной SQL-функцией;
- повторная серверная проверка не удваивает награду;
- кампанию с уже выполненными заданиями нельзя удалить, чтобы не уничтожать историю;
- награду кампании нельзя менять после первого выполнения — вместо этого нужно клонировать кампанию;
- использованный промокод нельзя удалить, его можно только отключить;
- административные операции остаются в `admin_audit_log`;
- API защищены Telegram-сессией, same-origin проверкой и rate limit.
