# MXM v0.47

- Новый раздел `/admin → Реклама`.
- Конструктор партнёрских заданий.
- Автопроверка подписки Telegram через Bot API.
- Ручная очередь проверки нестандартных заданий.
- Кампании: черновик, активна, пауза, завершена.
- Лимиты, приоритет, закрепление, расписание, внутренние заметки.
- Клонирование кампаний.
- Контроль бюджета и статистики выполнений.
- Промокоды с лимитом активаций.
- Партнёрские задания отображаются на странице «Задания и награды».
- Реферальный процент распространяется на партнёрские задания и промокоды.
- Новые события экономики: `sponsored_task`, `promo_code`.
- Все новые административные действия журналируются.
