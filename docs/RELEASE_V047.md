# MXM v0.47

Исторический административный релиз:

- Добавлены промокоды с лимитом активаций.
- Реферальные награды расширены на промокоды.
- Новые административные действия журналируются.
- Добавлены внутренние статусы, расписание, лимиты и заметки для существовавших на тот момент кампаний.

Кампании и задания рекламного типа из этой версии полностью удалены Market 2.0. Миграция 028 сохраняет только общий исторический аудит и удаляет live-таблицы, функции и клиентские/API-точки входа.
