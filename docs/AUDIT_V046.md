# MXM v0.46 — аудит и исправления

## Исправлено в этой версии

- Удалены оставшиеся публичные API старой системы игр. `/games` остаётся только безопасным редиректом в маркет.
- Telegram Stars начисляются только после серверного webhook Telegram. Клиентский `openInvoice` сам баланс не меняет.
- `pre_checkout_query` теперь сверяет payload, статус покупки и точное число Stars с записью в БД до подтверждения оплаты.
- Покупки Stars идемпотентны по `telegram_payment_charge_id` и ID покупки.
- Реферальная связь назначается только один раз, не допускает self-referral и ограничена первой неделей аккаунта.
- Реферальный бонус идемпотентен и начисляется только с системных эмиссий (`rewarded_ad`, `mission`, `stars`), а не с торгового оборота.
- Реклама ограничена максимум пятью подтверждёнными просмотрами в сутки. Ограничение есть и в БД, а не только в интерфейсе.
- Сырой `ton:...` адрес больше не выводится в заголовке Gift detail и не ломает мобильную вёрстку.
- Ордера больше не падают целиком из-за одного удалённого Gift/profile: повреждённая строка пропускается, имя имеет безопасный fallback.
- Из API старого игрового функционала удалён оставшийся внешний attack surface.
- Фильтры Gifts получают словари из всего активного рынка, а не только из первой загруженной страницы.
- При активных фильтрах клиент догружает дополнительные страницы до получения релевантных результатов или конца каталога.
- TonAPI каталог расширяется постепенно в фоне, с lock/cooldown, а не блокирует первый рендер рынка.
- Lottie-анимации ограничиваются по числу одновременно активных экземпляров на слабых мобильных устройствах.
- Realtime уже дебаунсится и не запускает обновления в скрытой вкладке; GET-запросы дедуплицируются и имеют короткий memory cache.
- Нижние sheet/drawer поддерживают swipe-down закрытие.

## Экономика v0.46

- Rewarded Ads: 50 виртуальных TON, максимум 5 подтверждённых просмотров/сутки, cooldown 30 минут.
- Рефералы: 5% от системных наград приглашённого пользователя.
- Комиссия торговли мемкоинами: 0.5% — sink и запись в economy ledger.
- Запуск мемкоина: 150 виртуальных TON — sink.
- Комиссия рынка Gifts: 2.5% — системное казначейство.
- Stars — отдельный источник платной эмиссии, каждая покупка записывается в ledger.

Это не делает экономику автоматически «идеальной»: после запуска нужно смотреть фактические DAU, среднюю эмиссию рекламы/заданий, оборот и sinks. Админка уже показывает ключевой поток экономики, поэтому коэффициенты можно корректировать по фактическим данным.

## Остаточный технический долг

- В проекте остаются ESLint warnings старого кода (`no-explicit-any`, `<img>`, `set-state-in-effect`). Ошибок ESLint нет.
- Полное наполнение всех Telegram Gift коллекций зависит от доступности и лимитов TonAPI; синхронизация теперь обходится постепенно и не обещает мгновенную полноту после первого запуска.
- Для production Stars обязателен HTTPS webhook Telegram и секрет webhook.
- Для production rewarded ads нужен server verification AdsGram.
- `npm audit` нужно запускать в CI/локально с доступом к npm registry.
